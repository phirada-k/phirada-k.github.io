Houdini Process for Lightning

For procedural steps for creating a starting point, scatter points were used on the surface of the object. In this project, the car model was used.

Once scattered the points, assign three different color to later use for different the starting time and different types of the lightning. In my case, I'm separating the points into three colors, and grouped them into three groups, which later can reduce the amount of lightning. For now I'm using green and blue.

Also project those scatter point on the ground (or where the end of the lightning will shoot to) using Ray node.

Using Add node to add lines between the two point on the car and the ground

Using for each node to create the line to generate in slightly different time for more realistic lightning. At the same time, using resample, edit and VOP node for flickering the lightning.

Lastly, for the sparks on the ground. Using attribute transfer when the lightning mesh touch the ground, to create a point as a source for sparks.

Then create sparks from particle simulation (popnet).
